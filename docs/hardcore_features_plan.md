# План реализации высокотехнологичных модулей Aniyume

Этот план описывает техническую реализацию четырех модулей, которые поднимут проект на уровень Enterprise/Research.

---

## 1. AI Computer Vision: Автоматическая сегментация (Smart Player)
**Задача:** Автоматически находить Opening, Ending и Recap без ручной разметки.

### Реализация:
- **Backend (Python Microservice):** Использование `PySceneDetect` с алгоритмом `ContentDetector`.
- **Алгоритм:** 
    1. Разбить видео на сцены на основе гистограмм яркости.
    2. Извлечь "хэш" (Image Fingerprint) из первой и последней сцены каждой серии.
    3. Сопоставить хэши: если сцена повторяется во всех сериях сезона — это **Opening**.
- **Оптимизация:** Анализировать не все кадры, а каждый 10-й. Скорость: ~10-15 секунд на всю серию при первом импорте, затем результат в БД.

## 2. WebAssembly & GPU Upscaling (Anime4K Integration)
**Задача:** Улучшение качества старого аниме прямо в браузере.

### Реализация:
- **Стек:** WebGL / WebGPU + Shaders (GLSL).
- **Подход:** Интегрировать `Anime4K` (набор шейдеров для апскейлинга и деноизинга).
- **Как это работает:** Видео рендерится не напрямую в `<video>`, а через WebGL-контекст, где шейдер в реальном времени применяет алгоритмы уточнения краев.
- **Производительность:** Работает на GPU пользователя (0 секунд задержки, 60 FPS).

---

## 3. WebRTC P2P Content Delivery
**Задача:** Пользователи делятся кусками видео друг с другом, экономя твой трафик.

### Реализация:
- **Библиотека:** `p2p-media-loader`.
- **Интеграция:** Перехват чанков HLS через `hls.js`.
- **Логика:** 
    1. Клиент запрашивает фрагмент видео.
    2. Проверяет наличие фрагмента у соседей по WebRTC.
    3. Если нет — качает с твоего сервера через HTTP и отдает соседям.
- **Профит:** Снижение нагрузки на сервер до 50-70% на популярных тайтлах.

---

## 4. Anti-Scraper Fingerprinting (Cybersecurity Layer)
**Задача:** Отличать реальных фанатов от ботов-парсеров.

### Реализация:
- **Frontend:** Снятие отпечатка браузера через `FingerprintJS` (Canvas, AudioContext, CanvasFonts).
- **Backend (Laravel Middleware):** 
    - Сбор телеметрии: время между кликами, наличие движений мыши, использование скрытых полей-ловушек (Honeypots).
    - Хранение рейтинга доверия (Trust Score) в Redis.
- **Действие:** Если подозрительно — выдаем 429 ошибку с задержкой 5 секунд (throttling), что делает парсинг экономически невыгодным.
