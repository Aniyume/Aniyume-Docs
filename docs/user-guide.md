# User guide

## Назначение

Этот документ описывает основные пользовательские сценарии Aniyume.

## 1. Регистрация и вход

1. Открыть `/register`.
2. Ввести имя, email и пароль.
3. После регистрации пользователь получает access token.
4. Для повторного входа открыть `/login` и ввести email/password.

После входа становятся доступны:

- профиль;
- избранное;
- список просмотра;
- история просмотра;
- комментарии;
- рейтинги;
- друзья;
- Watch Party.

## 2. Каталог anime

Пользователь может:

- открыть каталог;
- искать anime;
- фильтровать по статусу, году, жанру/тегу;
- сортировать список;
- открывать страницу anime.

## 3. Страница anime

На странице anime доступны:

- описание;
- постер/banner;
- tags;
- список episodes;
- comments;
- community statistics;
- recommendations;
- действия пользователя: status, favorite, rating.

## 4. Просмотр episodes

Пользователь может:

1. выбрать episode;
2. запустить player;
3. продолжить просмотр позже.

Backend сохраняет:

- `episode_id`;
- `progress`;
- `delta_time`;
- `completed`.

## 5. Список просмотра

Доступные статусы:

- `watching`;
- `planned`;
- `completed`;
- `on_hold`;
- `dropped`.

Чтобы убрать anime из списка, frontend отправляет:

```json
{
  "status": "not_watching"
}
```

## 6. Favorites

Пользователь может:

- добавить anime в избранное;
- открыть список избранного;
- проверить favorite status;
- удалить anime из избранного.

## 7. Ratings

Пользователь может поставить anime оценку.

Backend:

- создает или обновляет user rating;
- пересчитывает средний rating anime.

## 8. Comments

Пользователь может:

- оставить comment;
- увидеть свои comments;
- редактировать свой comment;
- удалить свой comment.

Ограничения:

- нельзя редактировать чужой comment;
- нельзя удалить чужой comment.

## 9. Friends

Пользователь может:

- искать других пользователей;
- отправлять friend request;
- принимать/отклонять заявки;
- смотреть список друзей.

## 10. Watch Party

Пользователь может:

1. создать room;
2. пригласить друга;
3. отправлять chat messages;
4. синхронизировать просмотр как host;
5. покинуть room;
6. закрыть room как host.

Важно:

- только host может управлять player sync;
- только host может закрыть room;
- realtime зависит от Reverb/WebSocket runtime.

## 11. Profile

В profile пользователь может:

- посмотреть данные аккаунта;
- обновить имя/bio/custom status;
- загрузить avatar;
- посмотреть статистику.

## Troubleshooting

Если пользователь не авторизован:

- private endpoints вернут `401`;
- нужно повторно войти.

Если Watch Party не синхронизируется:

- проверить Reverb server;
- проверить `NEXT_PUBLIC_REVERB_*` env;
- проверить websocket reverse proxy.
